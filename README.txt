# Дашборд финансового здоровья Т-Банка

## ?? Цель проекта
Демонстрация навыков финансового анализа на основе реальной отчётности Т-Банка (группа «Т-Технологии») по МСФО за 2025 год.

## ?? Что сделано
- Собраны данные из открытых источников (МСФО, новости, аналитика)
- Построена финансовая модель в Excel: P&L, Cash Flow, план-факт анализ
- Рассчитаны ключевые метрики: ROE, чистая маржа, динамика по кварталам
- Создан интерактивный дашборд с KPI-карточками и графиками
- Написаны SQL-запросы для агрегации данных (JOIN, GROUP BY, оконные функции)
- Выявлены проблемные зоны («Красные зоны») для руководства

## ??? Инструменты
- **Excel**: сводные таблицы, формулы, визуализация, условное форматирование
- **SQL**: агрегация, оконные функции, подзапросы (SQLite)
- **1С**: имитация выгрузки данных для анализа

## ?? Ключевые выводы
- Выручка выросла на **49%** год к году (до 1,4 трлн ?)
- ROE — **29,1%**, что выше среднего по рынку
- Ключевой риск: рост процентных расходов на **82,5%** давит на маржу
- Квартальная динамика показывает устойчивый рост от Q1 к Q4
